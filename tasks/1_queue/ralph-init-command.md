# Task — ralph-init-command

**Model:** sonnet · **Effort:** high · **Tokens estimated:** 10000 · **Attempts:** 0/3
**Allowed files:** ralph.sh, project/ralph.sh

## Context
Add `ralph.sh init <path>` and `ralph.sh update` subcommands so Ralph can bootstrap new
projects and keep their engine files current.

`init <path>` creates a complete Ralph-ready project at the given path:
- `ralph-aymm/` subfolder containing all engine scripts copied from this repo
- `tasks/{0_backlog,1_queue,2_active,3_done}/` at project root
- `.ralph/` and `handoffs/` at project root
- `planning/` folder for blueprint, style guide, phase plans
- Template `ARCHITECTURE.md` with all required sections and placeholder content
- `CLAUDE.md` copied as-is from this repo (it's generic — travels unchanged)
- `prompt.md` copied from this repo
- Starter `CHANGELOG.md` with header comment
- `.gitignore` covering STOP, .ralph/, node_modules, .env
- `.ralph-source` file recording the absolute path of this Ralph Loop repo
- `git init && git add -A && git commit -m "init: ralph-aymm engine boilerplate"`

`update` reads `.ralph-source` from the current directory and copies the latest engine
scripts from that path into `ralph-aymm/`, then commits the update.

Engine files to copy for both init and update (from repo root into `ralph-aymm/`):
`loop.sh`, `aymm-loop.sh`, `run_agent_task.sh`, `apply_changes.sh`, `provider-config.sh`,
`provider-status.sh`, `init-firewall.sh`, `Dockerfile`, `prompt.md`

`ralph.sh` itself is NOT copied into `ralph-aymm/` — the new project gets its own
`ralph-aymm/ralph.sh` generated by init. The engine scripts that run inside the
container (`loop.sh`, `aymm-loop.sh`) need `WORKDIR` set to the parent directory
(project root, one level up from `ralph-aymm/`). The init command patches this in
the copied scripts:
`sed -i 's|^WORKDIR=/workspace$|WORKDIR="$(cd "$(dirname "$0")/.." \&\& pwd)"|' ralph-aymm/loop.sh ralph-aymm/aymm-loop.sh`

The new project's `ralph-aymm/ralph.sh` is a copy of this repo's ralph.sh but with
the comment header updated to reflect the subfolder invocation path
(`bash ralph-aymm/ralph.sh`).
